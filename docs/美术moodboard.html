二、关键元素清单（所有资产统一使用）

纹样

青海波（重叠半圆波纹）、麻叶纹（_asanoha_ 星形几何）、云纹（层叠金弧）、霞带（横向雾带）。

质感

和纸颗粒（低透明度噪点覆层）、描金细线（1–2px）、深色底上的微光晕。

字体气质

标题：粗黑体+局部衬线点缀；数字/点数：几何无衬线。避免手写体。

角色

粗描边扁平、几何化；头像 8–12 个（武士/艺伎/商人/忍者/法师…），统一 3/4 侧视角。

四、定稿流程

1. 用 ①②③ 的提示词各出 4–6 张，挑出 3 张关键参考图。
2. 把选中的图片文件发我（或放到 assets/concept/ 目录），我做与现有程序化 UI 的对齐改造。
3. 音乐：Suno 生成候选 → 挑 4 首 → 交给我接替换 synth.gd 的占位音频（钩子已就绪）。
4. 换皮全程不改代码结构：颜色/贴图集中在 Theme 与 audio 库两处。
注意：AI 生成的参考图仅作内部风格定位。正式商用素材需确认所用生成服务的商用授权条款。
