# 《大富豪》美术风格指南 v1.0

> 本文固化游戏的视觉语言，是 M4 验收"美术对照风格指南逐项审查"的依据。
> 新增任何 UI/卡面/特效前先对照本文；与本文冲突的视觉改动需要先改本文。

## 1. 风格关键词

**和风 × 现代霓虹（P5 式构图）**：浮世绘纹样与和纸质感做底，描边扁平图形 + 霓虹金/朱红点缀。
深色底在 OLED 上更省电，也区别于传统"棋牌平台"审美。

- 深靛蓝底 + 朱红/描金主色
- 和纸颗粒、云纹/浪纹/市松/青海波装饰线
- 几何化中文标题字（毛笔感），倾斜排版制造张力
- 图形语言：斜切平行四边形、锯齿星芒、方块点阵

## 3. 卡面解剖（程序化绘制，`card_view.gd`）

- 基准尺寸 **72×100**；一切元素按 `s = 高度/100` 等比缩放，小尺寸（商城迷你卡/对手牌背）不得失衡
- 元素（由外到内）：描金外框(2px, 圆角7) → 内框细线 → 和纸颗粒 → 金色角饰 →
  左上点数牌匾(牌色底/白字) + 牌匾下角标花色 → 中心主题纹环(数字)/纹章水印(JQK) →
  中心大花色(投影 + 主色 + 米白内芯) → 右下小点数
- **牌背**：主题纹样满铺 + 角饰；所有绘制严格限制在牌面内（`clip_contents`）
- **JOKER**：主题色夜空渐变 + 像素画(达摩/仙鹤/狐面/河童)；大王带金色放射线，小王素面
- **主题例外**：♠3 单出 key=16.5 比王大（仅单张比较，不可跨牌型）；革命反转仅作用于 3..2 自然牌

## 4. 字体层级

| 层级 | 字体 | 字号 | 用途 |
|---|---|---|---|
| 标题 | title_font（毛笔感 CJK） | 24–34 | 界面标题/革命大字 |
| 强调 | display_font | 15–22 | 按钮/座位信息/状态 |
| 正文 | body_font（主题 default_font） | 14–18 | 说明/聊天/战绩 |

- 深底文字一律加 `1px 黑色阴影`（`_add_text_shadow`）
- 身份/积分允许彩色：正分绿、负分红、身份按 §2.2

## 5. 动效原则

| 动效 | 规格 |
|---|---|
| 出牌 | 向来源方位飞入 + 回弹缩放（TRANS_BACK），22s% 内完成 |
| 发牌 | 手牌逐张延迟 0.02s 淡入 |
| 全屏特效 | 革命/反革命/8切/一落千丈/交换，统一 1.6s，`fx_overlay.gd`，播完自释放 |
| 倒计时 | 最后 5s 每秒滴答音 |
| 选中牌 | 上浮放大 7% + 4px 亮金边 + 顶部金三角；未选中微压暗 |

- 特效像素化语言：方块点阵线条、锯齿轮廓、粗描边
- 特效不拦截鼠标；播放期间对局逻辑照常

## 6. 禁止事项

- 不引入照片位图素材（v1 全程序化绘制）
- 不使用纯色平铺的"棋牌绿"桌面
- 不在牌面/大厅使用超过 2 种主色的新配色（新主题需在 `skins.gd` 建完整色板）
- 不缩小后仍用大尺寸像素值的元素（一律带缩放系数）
