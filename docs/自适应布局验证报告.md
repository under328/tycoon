# 多设备自适应布局验证报告

> 验证方式: tools/adaptive_capture.gd 真实渲染截帧 + 逐张人工目检
> 截图矩阵: 4 档视口 × 7 页面 = 28 张 (builds/adaptive_*.png)

## 视口档位

| 档位 | 逻辑视口 | 对应设备 |
|---|---|---|
| PC | 1280×720 | 桌面窗口 |
| 平板 4:3 | 1280×960 | iPad 横屏 |
| 手机 20:9 | 1600×720 | 全面屏手机横屏 |
| 手机紧凑 | 1248×576 | 触屏(csf 1.25)横屏手机 |

## 覆盖页面

主菜单 / 联机大厅(入口) / 商城 / 联机帮助 / 新手引导 / 设置 / 格斗试炼(选牌)

## 验证结论

| 页面 | PC | 平板 | 手机20:9 | 手机紧凑 | 结论 |
|---|---|---|---|---|---|
| 主菜单 | ✓ | ✓ | ✓ | ✓ | 标题/徽章/卡扇/菜单项全部界内 |
| 联机大厅 | ✓ | ✓ | ✓ | ✓ | 三列布局, 附近主机面板左列不侵入 |
| 商城 | ✓ | ✓ | ✓ | ✓ | 列数随宽度 2/3/4 自适应, 等宽铺满 |
| 新手引导 | ✓ | ✓ | ✓ | ✓ | 内容列 900 封顶居中, 触屏字号加大 |
| 联机帮助 | ✓ | ✓ | ✓ | ✓ | 图文两栏居中 |
| 设置 | ✓ | ✓ | ✓ | ✓ | 整页滚动, 行全宽 |
| 格斗试炼 | ✓ | ✓ | ✓ | ✓ | 10 张候选一行排开(紧凑档可滚动) |

历史遗留问题(已修复): 新手引导双重挂载(页打不开)/商城关闭残留误报/
dog 阶段块错位导致遍历器假卡死 —— 均由本轮遍历器与截图矩阵定位。
