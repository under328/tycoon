# 移动端体验设计规范

本文沉淀手机/平板端的 UX 决策, 改动移动端相关代码前先对照本文。

## 视口与缩放

- 设计基准 1280×720, 拉伸 `canvas_items + expand`(逻辑视口恒 ≥ 基准);
- 触屏设备 `content_scale_factor = 1.25`(`Responsive.ui_scale()`):
  2340×1080 手机逻辑视口 ≈ 1248×576, 全部元素物理 +25%;
- 布局**按逻辑视口尺寸分支**(紧凑 = 高 <660), 不按设备型号分支;
- 触屏专属尺寸: 手牌 96×134、出牌区牌 70×98、按钮 116×52(字 21)、
  表情 48×48 —— 与全局缩放叠加, 手牌物理 ≈ 180px(+67%)。

## 布局红线

- 任何控件不得出屏或重叠: adaptive 测试含 `phone_compact`(1248×576)
  档与无重叠断言(手牌卡底 vs 操作行 / 出牌区 vs 手牌区), 改布局必跑;
- 大厅锚定为**带符号压缩**(高/宽不足时底部与右缘控件向内收);
- 帮助/引导紧凑档: 图示/圆点/翻页按钮钳到屏内;
- 牌桌状态/错误文字在紧凑档移到出牌区上方。

## 导航与防误触

- Android 返回手势/返回键 = `WM_GO_BACK_REQUEST`(不走 ESC):
  确认框 → 关框; 牌桌 → 返回确认框; 大厅 → 回首页; 首页 → 退出;
- 对局进行中离开(本地托管/联机弃局)一律弹确认框, 确认才离开;
- 联机房间码输入框每次进入联机页面自动清空。

## 输入

- 按钮热区下限 44px(`AppTheme.make_button` 触屏强制);
- 选牌: 原地点击翻转; 按住左右横扫批量选/取消(模式由首张牌状态钉定);
- 虚拟键盘弹出时聊天输入行整体上移键盘高度, 失焦复位;
- 触屏跳过保存的窗口尺寸/垂直同步(由系统全屏管理)。

## 反馈

- 声音: 牌桌隐藏(后台托管)时静音; 切后台 BGM/SFX 静音, 回前台恢复;
- 震动(`Input.vibrate_handheld`, 设置可关): 轮到你 40ms /
  该你返还换牌 40ms / 对局结束 80ms;
- "轮到你出牌"状态文字金色呼吸脉冲; 出牌区仅最后一手全亮,
  先前的牌做旧(降透明偏冷)。

## 性能与续航

- 移动端锁 60fps(`Engine.max_fps`);
- 对局 BGM 首次使用时惰性合成(冷启动只合成首页曲);
- GL Compatibility 渲染器 + ETC2/ASTC 纹理压缩(导出预设)。

## 联机

- 默认地址 127.0.0.1 在手机上无服务器: 4 秒回环守卫停止重连并给出
  三条出路(本机开房 / 填主机 IP / 粘贴邀请码);
- Tailscale 就绪条每 3 秒自动检测, Android 一键下载走官方 APK 直链
  (不跳 Google Play);
- 断线指数退避重连(2s×1.6 封顶 10s), 掉线期间座位由 AI 代管。
