## 判定标准

- 每个 E2E: 退出码 0 且打印各自 OK 标记(E2E_OK / VERSUS_OK)。
- B5: 三客户端视角 room_state 玩家数=4、座位互异、game_end 分数一致。
- C1/C3: 服务器日志 players 上升, 发现回包含新 peer。

## 执行中发现并修复的缺陷

1. **专用服端口占用时静默空转**: `--server` 绑定失败(如端口被残留进程占用,
   err=20)后进程不退出也无明确结论, 排查需靠 netstat。修复: net_node 新增
   `server_bind_failed` 信号, main.gd 服务模式收到后打印 `BIND_FAILED` 并以
   退出码 1 退出。已验证: 对占用端口再启服, exit=1 + 明确日志。
2. 测试脚本自身缺陷(非产品): e2e_quad 加入者缺 join 逻辑(补房间码轮询)、
   lan_join_probe 误用不存在的 net.chat(实为 send_chat), 均已修正。
3. 运维提示: 长驻服务器请留意残留进程——本次发现一个 4.7 小时前的旧服
   占用默认端口 24565-24567, 已清理。
