# 网络协议 v1（ENet / Godot 高层 multiplayer）

> 传输：`ENetMultiplayerPeer`，全部走 reliable 通道（回合制，消息小且稀）。
> 消息定义代码：`src/protocol/msg.gd`；可见信息裁剪：`src/protocol/view.gd`。
> payload 一律为 Dictionary，字段名蛇形命名；服务器对每个动作做 schema + 规则双重校验。

## 1. 连接与握手

```
客户端 → 服务器   hello { ver:int, session_token:String(可空) }
服务器 → 客户端   welcome { seat:int(-1=未入座), protocol_ok:bool, server_ver:int }
                  或 kicked { reason:String }   # 版本不符: reason="version"
```

- `ver` 不匹配 → 拒绝并提示更新（`kicked/version`）。
- 带 `session_token` 重连 → 服务器尝试恢复座位（见 §4）。

## 2. 大厅与房间

```
C→S  room_quick  { rules:Dictionary? }     # 快速匹配: 入等待中的公开房, 无则建新房
C→S  room_create { rules:Dictionary? }     # 建私房, 返回 6 位房间码
C→S  room_join   { code:String }
C→S  room_leave  {}
C→S  room_kick   { seat:int }              # 仅房主
C→S  room_start  {}                        # 仅房主, 满员或人+AI均可
C→S  bot_fill    {}                        # 空位补 AI (房主)

S→C  room_state { room_code, host_seat, players:[{seat, name, is_bot, online}], settings }
S→C  kicked     { reason }                 # "host"/"full"/"in_game"...
```

## 3. 对局（服务器权威）

```
C→S  game_play   { cards:[int] }
C→S  game_pass   {}
C→S  emoji       { id:int }                  # 快捷表情(限速客户端 1s)
C→S  chat        { text:String }             # 房内文本聊天(服务端限 80 字)
S→C  game_view   { view:Dictionary }        # 按座位私发, 结构见 §5
S→C  game_turn   { seat:int, remain_sec:int }
S→C  game_played { seat:int, combo:{type,key,len}, remain:int }   # remain=出牌者剩牌数
S→C  game_cleared{ seat:int }               # 清桌
S→C  revolution  { on:bool }
S→C  round_end   { identities:[int], points:[int], scores:[int] }
S→C  exchange    { picks:[{from:int, to:int, cards:[int], count:int}] }  # 自动交换展示
S→C  game_end    { scores:[int], identities:[int], stats:{seat:entry} }  # stats=人类玩家最新战绩
S→C  s_emoji     { seat:int, id:int }        # 表情广播
S→C  s_chat      { seat:int, text:String }   # 聊天广播
S→C  error       { code:String, msg:String }
```

## 4. 断线重连与托管

- 进房时服务器随 `room_state` 下发 `session_token`（客户端持久化于 `user://`）。
- 掉线：服务器保留座位 **30s 宽限**，立即由 AI 托管该座位；宽限内重连（`hello`+token）→ 服务器重发 `room_state` + 完整 `game_view`，玩家夺回座位。
- 客户端每 2s 自动重试连接；恢复失败超过 60s 提示回大厅。
- 所有回合等待以服务器计时器为准（`game_turn.remain_sec`），到点自动执行托管动作。

## 5. `game_view` 结构（按座位裁剪 — 防作弊核心）

```
{
  phase: "wait"|"deal"|"exchange"|"play"|"round_end"|"game_end",
  round: int, rules: Dictionary,
  hand: [int],                      # ★ 仅本人手牌(已排序); 其他人不出现
  counts: [int x4],                 # 各家剩余牌数
  finished: [int],                  # 已出完座位顺序
  turn: int, remain_sec: int,
  lead: combo?,                     # 当前需压的组合(领出权时为空)
  field: [ {seat, combo} ],         # 当前桌面(最近一出)
  revolution: bool, round_no: int,
  scores: [int x4], my_seat: int
}
```

不变式（单测覆盖）：任何 view 中除 `hand` 外不得出现其他玩家的具体牌 id。

## 6. 版本策略

- `msg.gd` 导出 `PROTOCOL_VERSION`；服务器与客户端不一致即拒绝。
- 客户端在主菜单显示当前版本号，被 `kicked/version` 时弹"请更新到新版"。
