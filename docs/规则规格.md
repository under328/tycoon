# 《大富豪》规则规格 v1（开发基线）

> 本文档是规则引擎（`src/rules/`）的实现契约。任何改动必须先改这里，再改代码与测试。
> 状态：已定稿（v1 范围）。带「变体」标记的项目可在房间设置中开关。

## 1. 牌的编码

- 一副 54 张：标准 52 张 + 小王（id=52）+ 大王（id=53）。
- 标准牌 id `0..51`：`点数 = 3 + id/4`（整除），`花色 = id % 4`。
  - 花色：0=♠ 1=♥ 2=♦ 3=♣。
  - 点数映射：3,4,5,6,7,8,9,10,J(11),Q(12),K(13),A(14),2(15)。**2 最大**。
- ♦3 = id **2**（首出标记牌，见 §5）。

## 2. 点序与革命

- 正常点序：3 < 4 < … < K < A < 2 < 王（王记为 16，恒最大）。
- **革命**（变体，默认开）：本局内任一玩家打出**四条**（含王辅助成四条，见 §4）后，点序反转（3 变最大，王变最小）。再次四条则恢复。反转次数在**局内**累计，换局重置。
- 顺子/階段的大小比较同样受反转影响（比较的是顺子最大端点）。

## 3. 发牌

- 每人 13 张，共 52 张。
- 带王（变体，默认开）：54 张洗匀后**随机扣 2 张死牌**（当局不可见不可用）；关王：52 张全发。
- 手牌对玩家私有；他人只可见牌数。

## 4. 牌型（v1 全集）

| 牌型 | 张数 | 说明 |
|---|---|---|
| 单张 | 1 | 含单王 |
| 对子 | 2 | 两张同点 |
| 三条 | 3 | 三张同点 |
| 四条 | 3+1 或 4 | 四张同点；**触发革命**（若开启） |
| 顺子 | ≥3 | 点数连续、花色不限，如 5-6-7 |
| 階段 | ≥3 | 同花色顺子（变体，默认开）；**独立牌型**，只能被同长度更大階段压 |

- **王为万能牌**（确定性解释，v1 规则）：
  - 组合中出现王时，王自动补位：对/三/四条中王补足同点数；顺子/階段中王填空缺位。
  - 顺子填洞后若王有剩余，**向上延伸**（例：3♠,4♠,王 → 3-4-5，端点 5；3,王,王 → 3-4-5）。
  - 王参与的顺序组合默认按最小端点解释；阶、花色按牌面（王可充当任意花色）。
  - **王+王**不能组成对子（两张王只能各自单出）。
- 牌型大小：只能「同牌型、同长度、更大点序」压制；不同牌型之间互不能压（階段与顺子互不兼容）。

## 5. 出牌流程

- **首局**：由持 **♦3** 者先出，且其第一手必须**包含 ♦3**。
- **后续每局**：由上一局**乞丐**先出，自由选择牌型，无 ♦3 限制。
- 跟牌：必须出「同牌型、同长度、点序更大」的组合，或 **Pass**。
- **清桌**：连续 Pass 至其余所有未出完者皆 Pass 时，桌面清空，由**最后出牌者**重新领出（自由牌型）。
- **8切**（变体，默认关）：单张 8 出牌后立即清桌并由其继续领出。
- 超时（联机）：跟牌 20s 未动作为 Pass；自由领出 20s 未动作则自动出最小合法组合。本地调试模式不限时。

## 6. 局结束与身份

- 率先出完手牌者依次获得身份：**大富豪 → 富豪 → 平民 → 乞丐**。
- 当第 3 名出完时**本局立即结束**，剩余未出完者为乞丐（其手牌作废，不计牌面）。
- 单局积分：大富豪 +2、富豪 +1、平民 −1、乞丐 −2（每局总和恒为 0）。

## 7. 局间交换

- 第 2 局起，重新发牌后执行**强制交换**（标准规则，弱者交最强牌）：
  - 乞丐 → 大富豪：交出手中最大的 2 张（王最大 > 2 > A > …）；
  - 平民 → 富豪：交出手中最大的 1 张。
  - 收牌方无动作。
- v1 为**自动交换**（无可选项），客户端播放交换展示；「自由挑选交换」列为后续变体。
- 交换完成后由乞丐领出新局。

## 8. 一场对局

- 默认 **3 局**制（可配 1/3/5），积分累加，终局总分定胜负（可并列）。
- 一场内第 n 局的发牌相互独立（死牌重新随机）。

## 9. 明确不做（v1 冻结）

都八（8 结局）、10 分裂、Joker 特殊效果（张数压等）、革命下王必出、自由交换、5 人以上局、局内复活。
