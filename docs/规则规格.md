# 《大富豪》规则规格 v2.0（设计文档 + 实现契约）

> 本文档是规则设计的完整规格，同时是规则引擎（`src/rules/`）的实现契约。
> 任何规则改动必须先改这里，再改代码与测试（见 §18 对照表）。
> 游戏内查看方式：主菜单【新手引导】（图文精简版）与牌桌右上角【规则】按钮。
> v2.0 变更：修正超时托管描述与实现对齐；新增托管/断线/房间/术语/问答/算法/配置/对照等章节。

## 1. 牌的编码

- 一副 54 张：标准 52 张 + 小王（id=52）+ 大王（id=53）。
- 标准牌 id `0..51`：`点数 = 3 + id/4`（整除），`花色 = id % 4`。
  - 花色：0=♠ 1=♥ 2=♦ 3=♣。
  - 点数映射：3,4,5,6,7,8,9,10,J(11),Q(12),K(13),A(14),2(15)。**2 最大**。
- ♦3 = id **2**（首出标记牌，见 §5）。
- 实现：`src/rules/cards.gd`；测试 `tests/suites/cards_test.gd`。

## 2. 点序与革命

- 正常点序：3 < 4 < … < K < A < 2 < 王（王记为 16，恒最大）。
- **革命**（变体，默认开）：本局内任一玩家打出**四条**（含王辅助成四条，见 §4）后，点序反转（3 变最大，2变最小）。再次四条则恢复。反转次数在**局内**累计，换局重置。
- 实现：`src/rules/game_state.gd`（触发与计数）、`src/rules/combo.gd#beats`（反转比较）。

## 3. 发牌

- 每人 13 张，共 52 张。
- 带王（变体，默认开）：54 张洗匀后**随机扣 2 张死牌**（当局不可见不可用）；关王：52 张全发。
- 手牌对玩家私有；他人只可见牌数。
- 每局发牌相互独立，死牌重新随机；发牌种子 = `hash(场种子:局号)`，整场可重放。
- 实现：`src/rules/game_state.gd#_deal_round`。

## 4. 牌型（v2 全集）

| 牌型 | 张数 | 说明 |
|---|---|---|
| 单张 | 1 | 含单王；**♠3 单出 key=16.5，比王(16)大** |
| 对子 | 2 | 两张同点 |
| 三条 | 3 | 三张同点 |
| 四条 | 4 | 四张同点；**触发革命** |

- **王为万能牌**（确定性解释，v2）：
  - **只解释为同点数组合**：组合中出现王时，若能构成对/三/四条则按同点解释（例：3♠+王+王 = 三条3）。
  - 不同点数 + 王 → 非法（王不做顺序补位）。
  - **王+王**不能组成对子（两张王只能各自单出或作为同点补位）。
  - 精确算法见 §16。
- 牌型大小：只能「同牌型、同长度、更大点序」压制；不同牌型之间互不能压。
- 实现：`src/rules/combo.gd#identify`；测试 `tests/suites/combo_test.gd`。

## 5. 出牌流程

- **首局**：由持 **♦3** 者先出，且其第一手必须**包含 ♦3**；**若 ♦3 为死牌，则随机首出且无此限制**。
- **后续每局**：由上一局**大贫民**先出，自由选择牌型，无 ♦3 限制。
- 跟牌：必须出「同牌型、同长度、点序更大」的组合，或 **Pass**。
- **清桌**：连续 Pass 至其余所有未出完者皆 Pass 时，桌面清空，由**最后出牌者**重新领出（自由牌型）；若最后出牌者已出完离场，则由其顺时针下一位未出完者领出。
- **8切**（基础规则，不可关闭）：任何包含 8 的组合出牌后立即清桌并由其继续领出；若这张 8 是最后一张手牌，按正常出完结算（8切不生效）。
- **超时与托管（联机）**：回合倒计时（默认 30s，可配 5–120s）归零时，该座位由**托管策略**接管——与 AI 托管完全同一套决策（见 §10）：能压出最接近的能压牌，压不过则 Pass，自由领出按 AI 策略出牌。倒计时最后 5 秒有滴答提示。本地调试模式不限时。
- 实现：`src/rules/game_state.gd#_do_play/_do_pass`；托管 `src/server/match_controller.gd` + `src/rules/ai/bot_player.gd`。

## 6. 局结束与身份

- 率先出完手牌者依次获得身份：**大富豪 → 富豪 → 贫民 → 大贫民**。
- 当第 3 名出完时**本局立即结束**，剩余未出完者为大贫民（其手牌作废，不计牌面）。
- 单局积分：大富豪 +2、富豪 +1、平民 −1、大贫民 −2（每局总和恒为 0）。
- 实现：`src/rules/game_state.gd#_finish_player`、`src/rules/scoring.gd`。

## 7. 局间交换

- 第 2 局起，重新发牌后执行**强制交换**（标准规则，弱者交最强牌）：
  - 大贫民 → 大富豪：交出手中最大的 2 张（王最大 > 2 > A > …）；
  - 贫民 → 富豪：交出手中最大的 1 张。
  - 收牌方手动选择获得牌数进行返回。
- 「自由挑选交换」列为后续变体。
- 交换完成后由大贫民领出新局。
- 实现：`src/rules/game_state.gd#_do_next_round/_give`。

## 8. 一场对局

- 默认 **3 局**制（可配置 1/3/5），积分累加，终局总分最高者胜（可并列，并列即并列胜场）。
- 一场内第 n 局的发牌相互独立（死牌重新随机）。

## 9. 明确不做（v1 冻结）

10 分裂、Joker 特殊效果（张数压等）、革命下王必出、自由交换、5 人以上局、局内复活。

## 10. AI 托管策略（托管 = AI = 超时接管，同一实现）

- **跟牌**：枚举手牌全部合法组合，出「离上一手点序距离最近」的能压牌（最不容易被压的弱牌）；同距离优先少用王；压不过则 Pass。
- **自由领出**：优先出牌数最多的组合（先跑为敬），同张数取当前点序下更弱的一手；首手含 ♦3 限制时只在含 ♦3 的组合中挑选。
- **革命感知**：以上"大小/强弱"判断全部基于反转后的点序。
- **换牌**：弱者交最强牌为自动；强者返还等量任意牌由玩家自选（AI 托管返还最弱牌），含倒计时。
- 托管触发时机：① 回合倒计时归零；② 座位离线（见 §11）；③ 空位补的 AI。
- 实现：`src/rules/ai/bot_player.gd`；测试 `tests/suites/net_logic_test.gd`（超时用例）。

## 11. 断线、离开与重连

- 玩家掉线（对局中）：座位立即由 AI 托管，对局继续；座位保留至**本场对局结束**（宽限）。
- 玩家重连（凭 `session_token`）：任意时刻可夺回座位并立即收到完整牌局视图；对局已结束则座位释放。
- 对局中主动【返回大厅】：等同掉线处理（弃局，AI 接管），需 3 秒内二次确认。
- 对局结束时的空座位（离线未归者）自动清除，可被新玩家加入。
- 实现：`src/server/room_manager.gd#peer_gone/hello`、`src/server/room.gd#end_match`。

## 12. 房间与匹配

- 三种开局：**快速匹配**（进入首个有空位的等待房间，没有则自动建房）、**创建房间**（6 位房间码）、**房间码加入**。
- 房主权限：空位补 AI、开始游戏、修改规则设置（仅开局前）、踢人。
- 开局后加入的新玩家只能等本局结束（房间回到等待态后可加入）。
- 再来一局：对局结束房间回到等待态，原座位保留，房主可直接再开。
- 实现：`src/server/room_manager.gd`。

## 14. 术语表

| 术语 | 含义 |
|---|---|
| 死牌 | 发牌后扣除的 2 张（带王局），当局无人可见可用 |
| 领出 | 清桌后自由选择牌型的第一手 |
| 跟牌 | 压制上一手同牌型更大组合 |
| 清桌 | 全员不要，桌面作废，最后出牌者重新领出 |
| 革命 | 四条触发点序反转 |
| 8切 | 任何含 8 的组合出牌即清桌并继续领出（不可关闭） |
| 托管 | 由 AI 替玩家决策（超时/掉线/空位） |
| 强制交换 | 局间弱者向强者交出最大牌 |

## 15. 边界问答（示例集，均有测试覆盖）

| 问 | 答 |
|---|---|
| 对 3 能压单张 K 吗？ | 不能，牌型不同互不压。 |
| 革命后什么压对 2？ | 对 3（点序反转，3 最大）。 |
| 3♠+王+王 是什么？ | 三条 3（王优先解释为同点组合）。 |
| 王+王 能出吗？ | 不能成对，只能各自单出或做补位。 |
| 革命后单王还最大吗？ | 否，反转后 3 最大、王最小（♠3 key 最高也垫底）。 |
| 最后一张 8 触发 8切 吗？ | 出完结算优先：玩家正常出完，8切不生效。 |
| 两张死牌里恰好有 ♦3？ | 首局改为随机首出，无 ♦3 限制。 |

## 16. 牌型识别精确算法 v2（与 `combo.gd#identify` 逐条对应）

```
1. n == 0 或 n > 4 → 非法。
2. n == 1 → 单张: 王 key=16; ♠3(id=0) key=16.5; 其余 key=牌值。
3. 全为王(无自然牌) → 非法(王+王不可组对)。
4. 统计自然牌点数 → 只有一种点数 v:
     n=2 → 对(key=v); n=3 → 三条(key=v); n=4 → 四条(key=v); n>4 → 非法。
5. 自然牌存在两种以上点数 → 非法(混合点数不可同出)。
```

- 王的数量恒等于窗口内空位数（牌数 − 自然牌数），无需额外判断。
- 同点数解释（第 3 步）优先于顺序解释（第 4 步），因此 `3♠+王+王` 是三条。

## 19. 进阶提示（新手向）

- 记住死牌里少了什么：革命局里少一张 2 或一张王，价值天差地别。
- 革命是你触发对自己有利的：先算清反转后谁手里剩大牌。
- 大富豪换牌拿到 2 张好牌时，优先组对子/三条，别急着单飞。
- 对局中随时点右上角【规则】翻看本规格的精简图文版。
