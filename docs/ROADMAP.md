## P1 · 服务器权威经济（跨设备钱包）

现状钱包为本地存档（可改档、换设备丢失）。方案：
1. [x] 阶段一(已交付): 本地钱包 + 备份码(导出/导入 JSON+zlib+校验和),
   设置页「备份」区块; 单测覆盖往返/篡改拒绝/全量字段恢复。
2. 阶段二：dedicated server 挂 `--wallet-db user://wallets.db`（SQLite 或 JSON 分片），
   客户端以 client_id 幂等上报对局结果，服务端复算积分发放（防作弊关键：
   服务端只信任自己的 MatchController 结算，不信任客户端上报的分数）。
3. 迁移：首登本地钱包快照上云，之后以云端为准、本地做缓存。
风险：中（需要迁移与幂等设计）。

## P2 · 对局回放

基础已具备：`seed + cfg` 可完整重放任何本地局（`_deal_round` 按局定随机）。
方案：对局记录条目扩容 `{seed, cfg, actions: [...]}` 落盘；
回放器 = 逐条 `GameState.apply` + table 只读渲染（禁操作）。
工作量：1-2 个会话；可复用格斗对战的观战广播路径（s_fight_state）。
