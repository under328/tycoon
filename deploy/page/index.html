四人联机纸牌 · 革命与階段 · Windows / Android
⬇ Windows 版Tycoon.exe · 双击即玩 · 免安装 ⬇ Android 版Tycoon-release.apk · arm64 · 直接安装

怎么开一局

  1. 房主打开游戏 → 大厅连接服务器 → 创建房间，把 6 位房间码发给朋友。
  2. 朋友在各自设备的大厅输入房间码加入；人不满时房主可"空位加AI"。
  3. 房主点开始游戏，连打 3 局，总分定胜负；打完可一键再来。

玩法速览

点序3 最小、2 次之、王最大； 跟牌同牌型同张数、点更大，或不要； 革命四条一出、大小颠倒； 階段同花色连牌自成牌型； 换牌乞丐把最好的牌孝敬大富豪——弱者也能翻盘。

自建服务器（可选）

Windows 版自带服务器模式：Tycoon.exe --headless --server --port 24565。 大厅里把地址填成你的 IP 即可。详细部署见项目 deploy/README.md。
